Gerenciador de Lucros

Gerencie suas sessões, acompanhe seus resultados e mantenha todo o seu histórico diretamente no seu computador.

Versão atual: 1.0.0
Windows
— — Funciona offline
⬇ Baixar para Windows

Requisitos

Windows 10 ou superior (64 bits). Não é necessário instalar Node.js, Rust ou qualquer outra ferramenta — basta baixar o instalador e executar.

Seus dados ficam no seu computador

  • Não existe login nem cadastro.
  • Seus registros ficam armazenados localmente, neste computador.
  • O programa funciona 100% offline.
  • Os dados não são enviados automaticamente para nenhum servidor.

Novidades da versão

Gerenciador de Lucros — aplicativo local, sem anúncios e sem cadastro.
